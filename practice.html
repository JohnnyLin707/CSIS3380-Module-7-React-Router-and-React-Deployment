2Part 2 · 基础路由 Home / About / Profile

把 src/App.jsx 替换为下面的内容 —— 为了专注路由本身，这个练习把所有组件都写在同一个文件里：

src/App.jsxJSX
// 一次性导入所有要用的路由组件
import { Routes, Route, Link, BrowserRouter } from 'react-router-dom';

// 三个页面组件
function Home() {
  return <h2>Home Page</h2>;
}

function About() {
  return <h2>About Page</h2>;
}

function Profile() {
  return <h2>Profile Page</h2>;
}

function App() {
  return (
    // BrowserRouter：包住整个应用
    <BrowserRouter>
      <div>
        {/* 导航链接 */}
        <nav>
          <Link to="/">Home</Link> |{' '}
          <Link to="/about">About</Link> |{' '}
          <Link to="/profile">Profile</Link>
        </nav>

        {/* 路由表：地址 → 组件 */}
        <Routes>
          <Route path="/" element={<Home />} />
          <Route path="/about" element={<About />} />
          <Route path="/profile" element={<Profile />} />
        </Routes>
      </div>
    </BrowserRouter>
  );
}

export default App;
terminal
npm run dev

运行后点击导航，确认三个页面可以无刷新切换。

3Part 3 · 动态路由 URL 参数 + useParams

添加带参数的路由

在 Routes 中添加JSX
{/* :id 是路径参数，/user/1、/user/2 都会匹配这一条 */}
<Route path="/user/:id" element={<UserPage />} />

创建 UserPage 组件

UserPage 组件JSX
import { useParams } from 'react-router-dom';

function UserPage() {
  // 取出 URL 中的 id 参数（与路径里的 :id 对应）
  const { id } = useParams();
  return <h2>User Profile for ID: {id}</h2>;
}

添加链接，模拟访问不同用户

导航链接JSX
<Link to="/user/1">User 1</Link>
<Link to="/user/2">User 2</Link>
🎯

动态路由的本质：一条 path="/user/:id" 路由可以匹配无数个地址，组件通过 useParams() 拿到具体值，再去查询对应的数据（真实项目中通常用这个 id 请求接口）。

LIVE动态路由演示 · /user/:id 点击用户，或把地址栏 # 后面改成 /user/2
除 useParams 外，演示中的「随机拜访一位用户」按钮还展示了 useNavigate 编程式导航；访问不存在的 ID 时给出友好提示。

4Part 4 · 嵌套路由 dashboard/*

创建 Dashboard 父组件（含子导航和 Outlet）与 Stats / Settings 子组件：

Dashboard / Stats / SettingsJSX
import { Outlet, Link } from 'react-router-dom';

function Dashboard() {
  return (
    <div>
      <h2>Dashboard</h2>
      <nav>
        <Link to="stats">Stats</Link> |{' '}
        <Link to="settings">Settings</Link>
      </nav>
      {/* 子路由渲染在这里 */}
      <Outlet />
    </div>
  );
}

function Stats() {
  return <h3>Stats Page</h3>;
}

function Settings() {
  return <h3>Settings Page</h3>;
}

然后定义嵌套路由 —— 注意父路径带 /*：

嵌套路由定义JSX
<Route path="dashboard/*" element={<Dashboard />}>
  <Route path="stats" element={<Stats />} />
  <Route path="settings" element={<Settings />} />
</Route>
💡

MemoryRouter 演示：下面这个演示与上方代码逻辑相同，但改用 <MemoryRouter>（内存路由器）—— 路由状态只存在于内存，不改变浏览器地址栏。它常用于单元测试，或像本页一样「一个页面里嵌入多个路由演示」的场景。演示中用 useLocation() 把内存中的当前路径显示了出来。

LIVE嵌套路由演示 · MemoryRouter 点击 Stats / Settings，观察底部「当前内存路径」
使用 MemoryRouter 时地址栏不变；若改用 HashRouter，地址会变成 #/dashboard/stats。
