Module 7 包含两大主题：

  • React Router —— React 生态中最常用的路由库，用来构建「单页面应用（SPA）」：多个页面视图共享同一个 HTML 文件，切换页面时不重新加载整个网页，地址栏 URL 随之变化。
  • 免费部署 —— 把前端应用发布到 Render、Vercel、Netlify、GitHub Pages 等平台，并解决单页面应用「刷新后 404」的经典问题。
💡

什么是客户端路由？传统多页应用每次点击链接都向服务器请求一个新 HTML；React Router 把「URL → 组件」的映射交给浏览器端的 JavaScript 处理，点击链接只切换组件，页面不刷新，因此切换更快、状态不丢失（例如输入框内容不会因为跳转而被清空）。
