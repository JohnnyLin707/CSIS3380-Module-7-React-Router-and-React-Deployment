实战：三步搭建路由

依据《React Router Tutorial Lab》与课堂代码 React Router 2 - S25（router-step1/2/3）整理。从零创建一个 Vite + React 项目，做出「布局 + 多页面 + 嵌套路由 + 404」的完整单页面应用。

🎯实验目标

  • 理解客户端路由的概念；
  • 在 React 项目中安装并设置 React Router；
  • 创建多个页面/视图并实现导航；
  • 学习路由参数与嵌套路由。

最终成品：一个带顶部导航的应用，可以在 Home / Blogs / Contact / Dashboard 之间切换，Dashboard 下还有 Stats 和 Settings 两个子页面，访问不存在的地址时显示 404。

3Step 3 · 基础路由 对应 router-step2

新建 pages/ 文件夹存放页面组件，然后重写 App.jsx：用 <BrowserRouter> 包住路由表。

src/App.jsxJSX
import ReactDOM from "react-dom/client";
import { BrowserRouter, Routes, Route } from "react-router-dom";
import Layout from "../pages/Layout";
import Home from "../pages/Home";
import Blogs from "../pages/Blogs";
import Contact from "../pages/Contact";
import NoPage from "../pages/NoPage";

function App() {

  return (
    // BrowserRouter：启用路由（本教材放在 App.jsx 中）
    <BrowserRouter>
      <Routes>
        {/* "/" 是父路由，Layout 是布局组件 */}
        <Route path="/" element={<Layout />}>
          {/* index：访问 / 时渲染 Home */}
          <Route index element={<Home />} />
          <Route path="blogs" element={<Blogs />} />
          <Route path="contact" element={<Contact />} />
          {/* "*" 通配路由：未匹配地址显示 404，放最后 */}
          <Route path="*" element={<NoPage />} />
        </Route>
      </Routes>
    </BrowserRouter>
  )
}

export default App;

5Step 5 · 嵌套路由 对应 router-step3

新建 Dashboard 组件，用 <Outlet /> 作为子页面的占位符；再创建 Stats 和 Settings 两个子页面组件：

src/pages/Dashboard.jsxJSX
import { Link, Outlet } from 'react-router-dom';

function Dashboard() {
    return (
        <div>
            <h2>Dashboard</h2>
            <nav>
                <ul>
                    {/* 相对路径：最终解析为 /dashboard/stats */}
                    <li><Link to="stats">Stats</Link></li>
                    <li><Link to="settings">Settings</Link></li>
                </ul>
            </nav>
            {/* Stats / Settings 子页面渲染在这里 */}
            <Outlet />
        </div>
    );
}

export default Dashboard;
src/pages/Stats.jsxJSX
function Stats() {
    return <h3>Statistics</h3>;
}

export default Stats;
src/pages/Settings.jsxJSX
function Settings() {
    return <h3>Settings Page</h3>;
}

export default Settings;

然后在 App.jsx 中加入嵌套路由，并在 Layout 导航里加上 Dashboard 链接：

src/App.jsx（最终版）JSX
import ReactDOM from "react-dom/client";
import { BrowserRouter, Routes, Route } from "react-router-dom";
import Layout from "../pages/Layout";
import Home from "../pages/Home";
import Blogs from "../pages/Blogs";
import Contact from "../pages/Contact";
import NoPage from "../pages/NoPage";
import Dashboard from "../pages/Dashboard";
import Stats from "../pages/Stats";
import Settings from "../pages/Settings";

function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Layout />}>
          <Route index element={<Home />} />
          <Route path="blogs" element={<Blogs />} />
          <Route path="contact" element={<Contact />} />
          {/* dashboard 是父路由，stats/settings 嵌在里面 */}
          <Route path="dashboard" element={<Dashboard />}>
            <Route path="stats" element={<Stats />} />
            <Route path="settings" element={<Settings />} />
          </Route>
          <Route path="*" element={<NoPage />} />
        </Route>
      </Routes>
    </BrowserRouter>
  )
}

export default App;
🎯

此时访问 /dashboard/stats：Layout 渲染主导航 → Dashboard 渲染自己的导航 → Stats 渲染在最内层的 Outlet。三个组件同时出现在页面上，这就是嵌套布局的效果。

❓常见问题

1. 点击链接后整个页面刷新了？

检查是否误用了 <a href="/blogs">。站内导航一律使用 <Link to="/blogs">。

2. 404 页面不显示？

确认 <Route path="*" …> 放在最后，并且在同一个 <Routes> 内。

3. 子页面没有出现在 Dashboard 里？

父组件 Dashboard 中必须放 <Outlet />，否则子路由无处渲染。

4. 相对路径的链接点出来地址不对？

<Link to="stats"> 是相对当前路由的。它只有在 Dashboard（/dashboard）内部使用时才解析为 /dashboard/stats；在顶层组件中请用绝对路径 /dashboard/stats。

5. npm run dev 报错找不到模块？

确认执行过 npm install react-router-dom，且导入名称拼写正确（react-router-dom，不是 react-router）。
