Tailwind + React Router 综合练习

依据《React Router Exercise Lab》与课堂提供的 components/ 文件夹整理：把 Header、Home、Projects、Team 四个静态组件改造成一个单页面路由应用，并用 Tailwind CSS 美化。

🎯练习目标

给定组件文件（Header.jsx、Home.jsx、Projects.jsx、Team.jsx、index.css），完成一个 Vite + React 应用，要求：

  • 把粉色导航区的 HOME / OUR TEAM / PROJECTS 三个链接改造成 React Router 导航；
  • 在中间主内容区渲染 Home、Team、Projects 三个页面；
  • 组件使用 Tailwind CSS，因此需要先安装并配置 Tailwind。
页面结构 ┌─────────────────────────────────────┐ │ HEADER（粉色导航：Home / Team / Projects）│ ← Header.jsx，始终显示 ├─────────────────────────────────────┤ │ │ │ 主内容区（根据路由切换） │ │ Home.jsx / Team.jsx / Projects.jsx │ ← 由 <Routes> 决定渲染哪个 │ │ └─────────────────────────────────────┘

components/Header.jsx（改造后）JSX
import { Link, NavLink } from "react-router-dom";

const Header = () => (
  <>
    <header>
      <h1>Header</h1>
    </header>

    <nav>
      <ul>
        {/* 原来是 <a href="index.html">，现在用 NavLink 无刷新导航 */}

        <li><NavLink to="/team">Our team</NavLink></li>

🧩用 Router 改造应用

核心思路：Header 始终显示，下方主内容区由路由决定渲染哪个页面组件。把 App.jsx 改成：

src/App.jsxJSX
import { BrowserRouter, Routes, Route } from "react-router-dom";
import Header from "../components/Header";
import Home from "../components/Home";
import Projects from "../components/Projects";
import Team from "../components/Team";

function App() {
  return (
    // 路由器包住整个应用
    <BrowserRouter>
      {/* Header 在 Routes 外面：不随路由切换重新渲染 */}
      <Header />

      <Routes>
        {/* 每条路由对应一个页面组件 */}
        <Route path="/" element={<Home />} />
        <Route path="/team" element={<Team />} />
        <Route path="/projects" element={<Projects />} />
      </Routes>
    </BrowserRouter>
  );
}

export default App;
src/main.jsxJSX
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import './index.css'    // Tailwind 指令 + 页面样式
import App from './App.jsx'

createRoot(document.getElementById('root')).render(
  <StrictMode>
    <App />
  </StrictMode>,
)
