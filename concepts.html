React Router 核心概念

依据教材《REACT ROUTER Example Guide and Tutorial》整理：路由器、路由容器、路由定义、导航组件、嵌套路由、重定向、动态参数与 404 处理。每个知识点都配有带中文注释的代码。

1什么是客户端路由 SPA 的灵魂

React Router 是 React 的声明式路由库，让你用同一个单页面应用（SPA）呈现多个视图，并在视图之间导航。

传统多页应用（MPA）单页面应用（SPA + React Router）
点击链接浏览器向服务器请求新 HTML，整页刷新JavaScript 拦截点击，只切换组件，无刷新
地址栏变成新网址同样变化（history API 或 hash）
速度每次都有白屏等待瞬时切换，体验接近原生 App
页面状态全部丢失React 状态保留（如输入框内容）
🎯

一句话理解：React Router 做的事，就是把「URL 地址」与「要渲染的 React 组件」对应起来 —— 地址变了，组件跟着变。

3三种路由器 BrowserRouter / HashRouter / MemoryRouter

路由器（Router）是整个路由系统的基础，它把「当前位置」提供给所有路由组件。React Router 提供三种，按场景选择：

组件URL 形态适用场景注意
BrowserRouter /dashboard（干净 URL） 生产环境首选 需要服务器配合：直接访问或刷新子路由时，服务器要返回 index.html，否则 404（见部署页）
HashRouter /#/dashboard 静态托管、GitHub Pages、无服务器配置时 URL 里带 #，但无需任何服务器配置，刷新不会丢页面
MemoryRouter （不在地址栏显示） 单元测试、React Native、嵌入式组件 路由状态只保存在内存中，刷新页面会回到初始状态

教材中的用法：BrowserRouter 包住整个应用

src/main.jsxJSX
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import { BrowserRouter } from 'react-router-dom'  // 1. 引入路由器
import App from './App.jsx'

createRoot(document.getElementById('root')).render(
  <StrictMode>
    {/* 2. 用 BrowserRouter 包住整个应用，路由功能才能生效 */}
    <BrowserRouter>
      <App />
    </BrowserRouter>
  </StrictMode>,
)
💡

放置位置有两种写法，都对：教材 S25 示例把 <BrowserRouter> 放在 App.jsx 里；V6 示例放在 main.jsx 里。推荐放在入口 main.jsx，与组件逻辑分离，结构更清晰。本站在线演示统一使用 HashRouter，这样双击 HTML 文件也能正常演示（原因见「免费部署」页）。

BrowserRouter 的关键点

  • 包住整个应用（放在最外层）；
  • 基于 HTML5 History API 保持 UI 与 URL 同步；
  • 使用干净的 URL：/dashboard 而不是 /#/dashboard。

4Routes 与 Route 路由表

<Routes> 是路由容器，所有 <Route> 都要写在它里面；同一时刻只有一条匹配的路由会渲染。

src/App.jsxJSX
import { BrowserRouter, Routes, Route } from "react-router-dom";
import Layout from "../pages/Layout";
import Home from "../pages/Home";
import Blogs from "../pages/Blogs";
import Contact from "../pages/Contact";
import NoPage from "../pages/NoPage";
import Dashboard from "../pages/Dashboard";
import Stats from "../pages/Stats";
import Settings from "../pages/Settings";

function App() {
  return (
    <Routes>
      {/* path="/"：根路径，Layout 作为整体布局组件 */}
      <Route path="/" element={<Layout />}>
        {/* index 路由：父路径精确匹配（即访问 /）时渲染 */}
        <Route index element={<Home />} />
        <Route path="blogs" element={<Blogs />} />
        <Route path="contact" element={<Contact />} />
        <Route path="dashboard" element={<Dashboard />}>
          <Route path="stats" element={<Stats />} />
          <Route path="settings" element={<Settings />} />
        </Route>
        {/* 通配路由：兜住所有未匹配的地址，当作 404 页，必须放最后 */}
        <Route path="*" element={<NoPage />} />
      </Route>
    </Routes>
  )
}

export default App;

Route 的三个核心概念

  • path：URL 模式，如 "/"、"blogs"、"*"；
  • element：匹配成功后渲染的 React 元素，如 element={<Home />}；
  • 嵌套：把子 <Route> 写进父 Route 内部，就形成嵌套路由。

路径的三种写法

写法示例说明
绝对路径（以 / 开头）path="/"、path="/blogs"从根开始匹配，用于顶层路由
相对路径（不以 / 开头）path="blogs"相对于父路由拼接；在 Layout（/）内部即 /blogs
嵌套拼接父 path="dashboard" + 子 path="stats"拼成 /dashboard/stats
通配符path="*"匹配任意未命中的地址（404）
路径参数path="/user/:id":id 是占位符，可用 useParams 读取
💡

index 路由：<Route index element={<Home />} /> 没有 path，表示「父路径被精确匹配时」渲染。例如父路径是 /，访问 / 时渲染 Home；访问 /blogs 时则渲染 Blogs。

5Link 与 NavLink 导航组件

Link：不刷新页面的链接

src/pages/Layout.jsxJSX
import { Outlet, Link } from "react-router-dom";

const Layout = () => {
    return (
        <>
            <nav>
                <ul>
                    <li>
                        {/* to 属性指定目标路径，替代原生 <a href> */}
                        <Link to="/">Home</Link>
                    </li>
                    <li>
                        <Link to="/blogs">Blogs</Link>
                    </li>
                    <li>
                        <Link to="/contact">Contact</Link>
                    </li>
                    <li>
                        <Link to="/dashboard">Dashboard</Link>
                    </li>
                </ul>
            </nav>

            {/* 子路由组件渲染在这里 */}
            <Outlet />
        </>
    )
};

export default Layout;
  • to 指定目标路径，可以是绝对路径（/dashboard）或相对路径（dashboard）；
  • 点击后阻止整页刷新（SPA 行为），只切换组件；
  • 内部导航请使用 <Link>，不要用 <a>。

NavLink：会「高亮当前页」的链接

src/components/Header.jsJSX
import React from 'react';
import { NavLink } from 'react-router-dom';

const Header = () => (
  <header>
    <span className="icn-logo"><i className="material-icons">code</i></span>
    <ul className="main-nav">
      {/* NavLink 与 Link 用法相同，激活时自动加上 class="active" */}
      <li><NavLink to="/">Home</NavLink></li>
      <li><NavLink to="/about">About</NavLink></li>
      <li><NavLink to="/teachers">Teachers</NavLink></li>
      <li><NavLink to="/courses">Courses</NavLink></li>
    </ul>
  </header>
);

export default Header;
✅

NavLink 的两种进阶用法：

1. end 属性：<NavLink to="/" end> 表示只在精确匹配 / 时才高亮（否则所有页面都会让「Home」高亮）。

2. 样式函数：style={({isActive}) => isActive ? {background: 'red'} : undefined}，根据激活状态动态设置样式。

6Outlet 与嵌套路由 布局模式

<Outlet /> 是「占位符」：父组件中，子路由匹配到的组件就渲染在 Outlet 的位置。这是实现「布局套页面」的核心。

src/pages/Dashboard.jsxJSX
import { Link, Outlet } from 'react-router-dom';

function Dashboard() {
    return (
        <div>
            <h2>Dashboard</h2>
            <nav>
                <ul>
                    <li>
                        {/* 相对路径：解析为 /dashboard/stats */}
                        <Link to="stats">Stats</Link>
                    </li>
                    <li>
                        <Link to="settings">Settings</Link>
                    </li>
                </ul>
            </nav>
            {/* Stats 或 Settings 渲染在这里 */}
            <Outlet />
        </div>
    );
}

export default Dashboard;

两层嵌套的完整效果

/ (Layout) ├── / → Layout + Home（index 路由） ├── /blogs → Layout + Blogs ├── /contact → Layout + Contact ├── /dashboard → Layout + Dashboard │ ├── /dashboard/stats → Layout + Dashboard + Stats │ └── /dashboard/settings → Layout + Dashboard + Settings └── /* → Layout + NoPage（404）
🎯

嵌套路由的行为：访问 /dashboard/stats 时，从外到内逐层匹配 —— Layout 渲染导航，Dashboard 渲染自己的导航，Stats 渲染在最内层的 Outlet 里。父子组件会同时显示，这就是嵌套布局。

7Navigate 重定向 自动跳转

<Navigate> 是「声明式重定向」：渲染它时，立即跳转到 to 指定的地址。最常见的用途是给父路径设置默认子页面。

src/components/App.jsJSX
import { Routes, Route, Navigate } from 'react-router-dom';

// 访问 /courses 时，index 路由触发，自动重定向到 /courses/html
<Route path="/courses" element={<Courses />}>
  {/* index：父路径 /courses 被精确匹配时渲染 Navigate */}
  {/* replace：替换当前历史记录，避免用户按「后退」卡在重定向上 */}
  <Route index element={<Navigate replace to="html" />} />
  <Route path="html" element={<HTML />} />
  <Route path="css" element={<CSS />} />
  <Route path="javascript" element={<JavaScript />} />
</Route>
💡

replace 的作用：默认的跳转会往历史记录里「追加」一条。访问 /courses → 重定向到 /courses/html 时，如果不用 replace，用户按「后退」会回到 /courses，然后又被重定向走，造成「后退键失效」的错觉。加上 replace 后，/courses 会被替换掉，后退直接回到上一个真实页面。

如果需要在事件处理函数中跳转（例如表单提交后），则使用 useNavigate：

编程式导航JSX
import { useNavigate } from 'react-router-dom';

function LoginButton() {
  const navigate = useNavigate();
  return (
    <button onClick={() => {
      // 登录成功后跳到首页
      navigate('/');
      // navigate(-1) 表示后退一步，等同于浏览器「后退」按钮
    }}>登录</button>
  );
}

8useParams 动态路由 URL 参数

路径中的 :id 是「路径参数」。同一个 /user/:id 路由可以匹配 /user/1、/user/2……组件内部用 useParams() 取出具体值。

动态用户页JSX
import { useParams } from 'react-router-dom';

function UserPage() {
  // 路径写的是 /user/:id，这里就取出 id
  const { id } = useParams();
  return <h2>User Profile for ID: {id}</h2>;
}

// 路由定义
<Route path="/user/:id" element={<UserPage />} />

// 链接
<Link to="/user/1">User 1</Link>
<Link to="/user/2">User 2</Link>
⚠️

注意：URL 参数永远是字符串。即使地址是 /user/1，typeof id 也是 'string'，需要数字比较时先 Number(id)。

9404 错误页面

用通配路由 path="*" 捕获所有未定义的地址：

src/pages/NoPage.jsxJSX
const NoPage = () => {
    return <h1>404</h1>
};

export default NoPage;
  • path="*" 匹配任何未命中的路由；
  • 必须放在路由表的最后（React Router 按匹配度选路由，通配符优先级最低，放最后最保险）；
  • 给用户友好的错误提示，例如返回首页的链接。

11最佳实践

路由结构

  • 把 <BrowserRouter> 放在应用根部（入口文件）；
  • 用 <Routes> 分组管理路由定义；
  • 路由从「最具体」排到「最通用」，* 放最后。

组件组织

  • 为共享导航创建布局组件（Layout）；
  • 用 <Outlet /> 渲染子路由；
  • 页面组件放在专门的文件夹（如 src/pages/）。

路径约定

  • 顶层导航用绝对路径（/dashboard）；
  • 嵌套导航用相对路径（stats）；
  • URL 保持简单直观。

导航模式

  • 站内导航用 <Link> 或 <NavLink>；
  • 内部链接不要用 <a> 标签（会整页刷新）；
  • 在各个布局中保持一致的导航 UI。
