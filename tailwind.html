Tailwind CSS v4 + React/Vite 配置

依据《Tutorial: Implementing Tailwind CSS v4.x (Beta) in a React + Vite App》整理。v4 最大的变化：不再需要 tailwind.config.js 和 PostCSS，改用 Vite 插件 + CSS 优先配置。

1前提条件

  • Node.js v20+；
  • 了解 Vite、React 与 CSS 基础；
  • Tailwind v4 依赖较新的 CSS 特性，过旧的浏览器可能无法完整支持。

2创建 Vite + React 项目

terminal
npm create vite@latest my-app --template react
cd my-app
npm install

# TypeScript 版本：
npm create vite@latest my-app --template react-ts

3安装 Tailwind v4

terminal
npm install tailwindcss @tailwindcss/vite
  • tailwindcss：核心引擎；
  • @tailwindcss/vite：v4 新增的 Vite 集成插件。
💡

v4 的变化：不再需要手动安装 postcss 和 autoprefixer，也不再强制需要 tailwind.config.js。

4配置 Vite

编辑 vite.config.js，加入 tailwindcss 插件：

vite.config.jsJS
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [
    react(),
    // 让 Tailwind 新引擎直接接入 Vite 构建流程
    tailwindcss(),
  ],
})

该插件让 Tailwind 直接集成进 Vite 的构建管线；默认情况下你不再需要 tailwind.config.js（除非需要高级配置）。

5设置 CSS 文件

创建或打开 src/index.css，用一行 @import 引入 Tailwind（v3 需要三行 @tailwind 指令，v4 精简为一行）：

src/index.cssCSS
@import "tailwindcss";
src/main.jsxJSX
import './index.css'   // 在入口引入

6在 React 中使用 Tailwind 类

src/App.jsxJSX
export default function App() {
  return (
    // min-h-screen：最小高度一屏；flex 居中
    <div className="min-h-screen bg-gray-100 flex items-center justify-center">
      <h1 className="text-4xl font-bold text-blue-600">
        Hello, Tailwind v4!
      </h1>
    </div>
  )
}

Tailwind v4 的增强能力：

  • 更多工具类支持动态任意值（不必预先定义）；
  • 新变体：@starting-style、not-*、容器查询等；
  • 通过 CSS 变量进行主题定制（见下一节）。

7自定义主题 CSS 优先配置

v4 把大量定制从 JS 配置转移到 CSS：用 @theme 定义设计令牌（design tokens）：

src/index.cssCSS
@import "tailwindcss";

@theme {
  /* 自定义颜色令牌 */
  --color-primary: #1f2937;
  /* 自定义字体 */
  --font-display: "Inter", sans-serif;
  /* 也可以声明断点、间距等令牌 */
  /* --breakpoint-xl: 1280px; */
}

之后在 JSX 中直接使用这些令牌生成的类：

使用自定义令牌JSX
<div className="text-primary">
  Custom primary color
</div>

如果仍想使用 JS 配置，可以用 @config 引入：

兼容 JS 配置CSS
/* 需要 tailwind.config.js 时取消注释 */
/* @config "./tailwind.config.js"; */

8生产构建与清除未用样式

terminal
npm run build

Tailwind 会自动清除未使用的类。注意：避免用字符串拼接动态生成类名（如 'bg-' + color），否则构建时无法识别、样式会丢失；请写完整的类名。

9v3 → v4 迁移要点

  • 使用 npx @tailwindcss/upgrade 辅助迁移；
  • 删除旧的 PostCSS 配置；
  • 把 @tailwind base; @tailwind components; @tailwind utilities; 三行替换为 @import "tailwindcss";；
  • Vite 项目改用 @tailwindcss/vite 插件；
  • 定制内容迁移到 CSS 的 @theme 中。
项目v3v4
引入方式@tailwind base/components/utilities@import "tailwindcss";
构建集成PostCSS 插件 + tailwind.config.js@tailwindcss/vite 插件
配置文件必须 tailwind.config.js默认不需要，可选 @config
主题定制config.js 的 theme 字段CSS 的 @theme
额外依赖postcss + autoprefixer无

10常见问题

现象排查
样式完全不生效检查 index.css 是否只有一行 @import "tailwindcss"; 且被 main.jsx 引入；vite.config.js 是否加了 tailwindcss() 插件
部分类名无效确认类名写全（不要字符串拼接）；v4 中部分默认值变化，查阅官方文档的升级说明
自定义颜色不生效@theme 必须放在 @import "tailwindcss"; 之后；变量名需以 --color- 等规定前缀开头
还留着旧 postcss.config.js删除它，v4 由 Vite 插件接管，重复配置可能冲突
构建产物很大确认没有动态拼接类名；生产构建会自动 purge
