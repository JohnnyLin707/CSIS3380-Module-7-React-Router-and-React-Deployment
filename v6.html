React Router V6 · 课程目录应用

依据课堂代码 React Router-V6（0~4 共 5 个递进项目）整理。这是一个「前端课程目录」网站，五步递进：安装声明路由 → NavLink 导航 → 嵌套路由 → 子链接与重定向 → 404 页面。

📋项目概览

这是一个课程目录网站（Course Directory），包含四个顶层页面：

  • Home：课程目录首页介绍；
  • About：关于页面（通过 props 接收标题 title）；
  • Teachers：教师列表（从 data/teachers.js 读取）；
  • Courses：课程页，内部再分 HTML / CSS / JavaScript 三个子页面。
/ ├── / → Home ├── /about → About（props.title = "About"） ├── /teachers → Teachers（教师列表） └── /courses → Courses（父组件：子导航 + Outlet） ├── /courses → 自动重定向到 /courses/html（index + Navigate） ├── /courses/html → HTML 课程列表 ├── /courses/css → CSS 课程列表 └── /courses/javascript → JavaScript 课程列表 * → NotFound（404，第 4 步新增）

0第 0 步 · 安装与声明路由

创建项目后安装依赖：

terminal
npm install react-router-dom

在入口文件用 <BrowserRouter> 包住应用 —— 注意本系列与 S25 的写法不同：路由器放在 index.js 里，而不是 App 组件里：

src/index.jsJSX
import React from 'react';
import ReactDOM from 'react-dom/client';
import { BrowserRouter } from 'react-router-dom';
import './index.css';
import App from './App';

const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(
  <React.StrictMode>
    {/* 路由器包住整个应用，App 内部只管路由表 */}
    <BrowserRouter>
      <App />
    </BrowserRouter>
  </React.StrictMode>
);

然后在 App.js 中声明最初的两条路由：

src/App.js（第 0 步）JSX
import React from "react";
import { Route, Routes } from "react-router-dom";

// App 组件
import Home from "./components/Home";
import About from "./components/About";
import Header from "./components/Header";

function App() {
  return (
    <div className="container">
      {/* Header 是常驻的顶部导航，放在 Routes 外面 */}
      <Header />
      <Routes>
        {/* path="/" 匹配根地址 */}
        <Route path="/" element={<Home />} />
        {/* path="about" 匹配 /about（不带 / 也是绝对路径的简写） */}
        <Route path="about" element={<About />} />
      </Routes>
    </div>
  );
}

export default App;
💡

注意 Header 的位置：Header 放在 <Routes> 外面，所以它不随路由切换而重新渲染，始终显示 —— 这比「布局组件 + Outlet」更简单的替代方案，适合只有顶部导航的场景。

1第 1 步 · NavLink 导航

第 0 步的 Header 里用的是普通 <a href="#">（点击没反应）。第 1 步改用 <NavLink>，并补全四个页面的路由：

src/components/Header.js（第 1 步）JSX
import React from 'react';
import { NavLink } from 'react-router-dom';

const Header = () => (
  <header>
    <span className="icn-logo"><i className="material-icons">code</i></span>
    <ul className="main-nav">
      {/* NavLink：当前地址匹配时自动加上 active 类，导航高亮 */}
      <li><NavLink to="/">Home</NavLink></li>
      <li><NavLink to="/about">About</NavLink></li>
      <li><NavLink to="/teachers">Teachers</NavLink></li>
      <li><NavLink to="/courses">Courses</NavLink></li>
    </ul>
  </header>
);

export default Header;
src/App.js（第 1 步）JSX
import React from 'react';
import { Route, Routes } from 'react-router-dom';

import Header from './Header';
import Home from './Home';
import About from './About';
import Teachers from './Teachers';
import Courses from './Courses';

const App = () => (
    <div className="container">
      <Header />
      <Routes>
        <Route path="/" element={<Home />} />
        {/* 通过 props 把标题传给 About 组件 */}
        <Route path="/about" element={<About title="About" />} />
        <Route path="/teachers" element={<Teachers />} />
        <Route path="/courses" element={<Courses />} />
      </Routes>
    </div>
);

export default App;
✅

用 CSS 给激活链接上色：NavLink 激活时会输出 class="active"，写一条 .main-nav a.active { color: white; } 就能高亮当前页。也可以用样式函数：style={({isActive}) => isActive ? {background:'red'} : undefined}。

2第 2 步 · 嵌套路由 Courses 下的三个子页面

给 /courses 加上 /*（允许它带子路径），并把 html / css / javascript 三条子路由挂进去：

src/App.js（第 2 步）JSX
import React from 'react';
import { Routes, Route, Navigate } from 'react-router-dom';

import Header from './Header';
import Home from './Home';
import About from './About';
import Teachers from './Teachers';
import Courses from './Courses';

const App = () => (
    <div className="container">
      <Header />
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About title="About" />} />
        <Route path="/teachers" element={<Teachers />} />
        {/* path="/courses/*"：* 表示 courses 后面还可以跟子路径 */}
        <Route path="/courses/*" element={<Courses />}>
          {/* Write routes here... */}
          {/* 暂时留空：下一步填入子路由 */}
        </Route>
      </Routes>
    </div>
);

export default App;
⚠️

v6 的新写法：v5 中嵌套路由写作 path="/courses" 且子 Route 自带完整路径；v6 中父路由写 path="/courses/*"，子路由只写相对路径片段（path="html"），拼接后得到 /courses/html。

3第 3 步 · 子链接与重定向

填入子路由，并用 index + Navigate 让 /courses 自动跳到 HTML 页：

src/App.js（第 3 步）JSX
import React from 'react';
import { Routes, Route, Navigate } from 'react-router-dom';

import Header from './Header';
import Home from './Home';
import About from './About';
import Teachers from './Teachers';
import Courses from './Courses';
import HTML from './courses/HTML';
import CSS from './courses/CSS';
import JavaScript from './courses/JavaScript';

const App = () => (
    <div className="container">
      <Header />
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About title="About" />} />
        <Route path="/teachers" element={<Teachers />} />
        <Route path="/courses" element={<Courses />}>
          {/* 访问 /courses 时自动重定向到 /courses/html */}
          {/* replace：替换历史记录，后退按钮不会卡住 */}
          {/* <Route index element={<Navigate replace to="html" />} /> */}
          <Route path="html" element={<HTML />} />
          <Route path="css" element={<CSS />} />
          <Route path="javascript" element={<JavaScript />} />
          {/* 注意 Courses.js 中的 <Outlet />：它决定子路由渲染的位置 */}
        </Route>
      </Routes>
    </div>
);

export default App;

Courses 组件负责子导航和 Outlet：

src/components/Courses.jsJSX
import React from 'react';
import { Outlet, NavLink } from 'react-router-dom';

const Courses = () => (
  <div className="main-content courses">
    <div className="course-header group">
      <h2>Courses</h2>
      <ul className="course-nav">
        {/* 相对路径：解析为 /courses/html 等 */}
        <li><NavLink to="html">HTML</NavLink></li>
        <li><NavLink to="css">CSS</NavLink></li>
        <li><NavLink to="javascript">JavaScript</NavLink></li>
      </ul>
    </div>

    {/* HTML / CSS / JavaScript 三个子页面渲染在这里 */}
    <Outlet />
  </div>
);

export default Courses;

其中一个子页面组件（三个文件结构相同，只是导入的数据不同）：

src/components/courses/HTML.jsJSX
import React from 'react';
import Course from './Course';
import { HTMLCourses } from '../../data/courses';

const HTML = (props) => {
  // 把数据映射成课程卡片数组
  let courses = HTMLCourses.map((course) => {
    return <Course title={course.title}
                   desc={course.description}
                   img={course.img_src}
                   key={course.id} />   // key 帮助 React 识别列表项，必须唯一
  });
  return (
    <div>
      <ul>
        {courses}
      </ul>
    </div>
  );
}

export default HTML;

4第 4 步 · 404 页面

最后加入通配路由和 NotFound 组件：

src/App.js（第 4 步 · 最终版）JSX
import React from 'react';
import { Routes, Route, Navigate } from 'react-router-dom';

import Header from './Header';
import Home from './Home';
import About from './About';
import Teachers from './Teachers';
import Courses from './Courses';
import NotFound from './NotFound';
import HTML from './courses/HTML';
import CSS from './courses/CSS';
import JavaScript from './courses/JavaScript';

const App = () => (
    <div className="container">
      <Header />
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About title="About" />} />
        <Route path="/teachers" element={<Teachers />} />
        <Route path="/courses" element={<Courses />}>
          {/* index 路由：/courses 被精确匹配时重定向到 html */}
          <Route index element={<Navigate replace to="html" />} />
          <Route path="html" element={<HTML />} />
          <Route path="css" element={<CSS />} />
          <Route path="javascript" element={<JavaScript />} />
        </Route>
        {/* 通配路由：兜住所有未匹配地址，放在最后 */}
        <Route path="*" element={<NotFound />} />
      </Routes>
    </div>
);

export default App;
src/components/NotFound.jsJSX
import React from 'react';

const NotFound = () => (
  <div className="main-content not-found">
    <i className="material-icons icn-error">error_outline</i>
    <h2>Page Not Found</h2>
  </div>
);

export default NotFound;
